# HTML5 Native Design — Bundle Agent

This bundle agent wraps the individual **HTML5 Native Design** specialist from the `html5-native-design` individual plugin. Use it for cross-cutting questions about the native-HTML5 stack: how the three skills (`htmx`, `web-animations-api`, `html5-native-design`) compose into a single site, what to use where, and how to migrate from a heavier SPA stack.

For deep per-skill guidance, activate the individual specialist instead.
