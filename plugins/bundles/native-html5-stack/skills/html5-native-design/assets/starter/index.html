3. Animated <details> / <summary>

What is container queries?

Container queries let a component adapt its layout based on its own size, not the viewport. container-type: inline-size turns an element into a container; @container queries that element.

What is :has()?

The relational selector. Lets CSS reach up the tree based on descendant state — e.g. :has(:checked) for a CSS-only toggle.
