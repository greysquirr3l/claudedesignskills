Faking ::nth-letter with zero JavaScript

The ::nth-letter pseudo-element has been requested since 2003 and still doesn't exist. But every effect people want from it can be built today in pure HTML5 + CSS — you just pay for it in markup. Author one <span> per glyph, then let :nth-child, odd / even, and sibling-index() do the work the selector would have done natively.

The contract: a screen reader must still read the word, not F · R · A · C · T · U · R · E. Every demo word below carries role="text" + aria-label on the wrapper, so the split is purely visual. This is the one accessibility detail the splitting approach lives or dies on.

Demo 01 — odd / even

Alternating skew ::nth-letter(odd|even)

Chris Coyier's hypothetical 2011 example, verbatim — odd letters skew one way, even the other, each on its own colour block. ::nth-letter(odd) becomes span:nth-child(odd). No fancy features required; this works in every browser shipping today.

FRACTURE

✦ Imaginary native syntax
h1::nth-letter(odd) {
  transform: skewY(-15deg);
  background: #8B3F3F;
}
h1::nth-letter(even) {
  transform: skewY(15deg);
  background: #C97A7A;
}
✓ Real, pure CSS today
<!-- one span per glyph -->
<p role="text" aria-label="FRACTURE">
  <span>F</span><span>R</span> …
</p>

.word span:nth-child(odd)  { transform:skewY(-15deg) }
.word span:nth-child(even) { transform:skewY(15deg) }

Demo 02 — paint per index

Spectral hue oklch() + index

The pure-paint case (just color) — the easiest family of effects. Here each letter steps 40° around the OKLCH hue wheel. The live demo hardcodes :nth-child so it renders everywhere; the scalable version derives the hue from sibling-index() in a single declaration, length-independent.

SPECTRUM

✓ Works everywhere (hardcoded)
span:nth-child(1) { color:oklch(.82 .2 0) }
span:nth-child(2) { color:oklch(.82 .2 40) }
span:nth-child(3) { color:oklch(.82 .2 80) }
/* …one rule per glyph… */
✦ Length-independent (Chrome 138+)
/* one rule, any word length */
.word span {
  color: oklch(
    0.82 0.2
    calc(sibling-index() * 40deg)
  );
}

Demo 03 — staggered delay

Kinetic wave animation-delay × index

Each glyph runs the same bob keyframe, offset by its position — the classic ocean-wave headline. This is the per-letter twin of your Pattern Lab sibling-index() list-stagger demo. Honours prefers-reduced-motion.

CASCADE

✓ Works everywhere (hardcoded)
@keyframes bob {
  0%,100% { translate:0 0 }
  50%     { translate:0 -.32em }
}
span { animation:bob 1.3s infinite }
span:nth-child(2){animation-delay:.09s}
span:nth-child(3){animation-delay:.18s}
✦ Length-independent (Chrome 138+)
/* delay scales itself */
.word span {
  animation: bob 1.3s infinite;
  animation-delay: calc(
    0.09s * (sibling-index() - 1)
  );
}

Demo 04 — arithmetic selectors

Every third glyph ::nth-letter(3n)

The literal arithmetic case. :nth-child(3n) lights up every third letter — swap in 3n+1, 2n, or any An+B formula. This is exactly the flexibility the imaginary ::nth-letter(3n) promised.

INTERVAL

.word span            { color: var(--dim) }
.word span:nth-child(3n) { color: var(--lime); text-shadow: 0 0 22px … }
/* nth-child takes the full An+B microsyntax: 3n, 2n+1, -n+3, even, odd … */

Demo 05 — interactive · :has()

Reactive bloom :hover + :has()

Hover any letter: it blooms, the rest dim, and both neighbours lean in. The previous neighbour is reached with the :has() parent selector (span:has(+ span:hover)), the next one with the + combinator. Genuinely impossible without JS until recently — now pure CSS. (Hover the word →)

REACTIVE

.word:hover span            { color:var(--faint) }            /* dim the field   */
.word span:hover            { transform:translateY(-.22em) scale(1.45) } /* bloom */
.word span:hover + span     { transform:scale(1.15) }       /* next leans in */
.word span:has(+ span:hover){ transform:scale(1.15) }       /* prev leans in */

Demo 06 — looping sweep

Travelling shimmer staggered glow

A light source that walks left-to-right across the word forever — same staggered-delay mechanism as the wave, but glowing a single glyph at a time. Pairs an OKLCH cyan/violet text-shadow with the index offset.

EMERGENT

@keyframes sweep {
  0%,70%,100% { color:var(--faint); text-shadow:none }
  18%        { color:#fff; text-shadow:0 0 20px cyan, 0 0 40px violet }
}
.word span            { animation:sweep 2.6s infinite }
.word span:nth-child(n) { animation-delay:calc(.12s * n) } /* the sweep */

Demo 07 — irregular timing

Neon flicker per-glyph duration

The key distinction from the stagger demos: each letter gets its own animation-duration, not just an animation-delay offset. Pick irrational-looking values (3.1 s, 4.7 s, 2.3 s …) and the letters naturally drift out of phase, producing the chaotic feel of actual neon-tube ageing — no randomness in the CSS required.

SIGNAL

✓ Works everywhere (hardcoded)
/* vary DURATION, not just delay */
span { animation:neon-flicker linear infinite }
span:nth-child(1){animation-duration:3.1s}
span:nth-child(2){animation-duration:4.7s}
span:nth-child(3){animation-duration:2.3s}
/* irregular primes → natural desync */
✦ Formula (Chrome 138+)
/* irrational multiplier = chaos */
.word span {
  animation-duration: calc(
    2s + sibling-index() * 0.79s
  );
}

Demo 08 — 3D transform

Solari flip board perspective + rotateX

perspective on the parent + rotateX animation per glyph + staggered delay = a mechanical departure-board flip, zero JS. Each tile blanks out at 90° (when it's edge-on to the viewer) then reappears from the back. Letters flip on independent schedules — no choreographed block tick.

DEPARTS

✓ Works everywhere (hardcoded)
@keyframes flip-tile {
  0%      { transform:rotateX(0);      opacity:1 }
  40%,60% { transform:rotateX(90deg); opacity:0 }
  100%    { transform:rotateX(0);      opacity:1 }
}
.word      { perspective:800px }
.word span { animation:flip-tile 5s infinite }
✦ Length-independent (Chrome 138+)
/* delay cascades automatically */
.word span {
  animation: flip-tile 5s infinite;
  animation-delay: calc(
    0.3s * (sibling-index() - 1)
  );
}

Demo 09 — odd vs even keyframes

Chromatic glitch text-shadow + jitter

A red shadow shifted left and a cyan shadow shifted right are permanently on, simulating chromatic aberration. Odd and even children then run different shake keyframes so no two neighbours jitter at the same moment. Synchronised shaking just looks like the word is trembling — the desync is what makes it feel genuinely broken.

CORRUPT

.word span {
  text-shadow: -2px 0 oklch(.72 .22 25), 2px 0 oklch(.72 .22 200); /* always on */
}
span:nth-child(odd)  { animation: glitch-a 4.2s step-end infinite }
span:nth-child(even) { animation: glitch-b 3.5s step-end infinite }
/* glitch-a fires at 88–99%, glitch-b at 80–89% → never overlap */

Demo 10 — bidirectional transition

Typewriter dissolve transition-delay reversal

Hover the word: letters materialise left→right. Move away: they dissolve right→left. Both directions use the same CSS transition — the only difference is the transition-delay order flips between base state and :hover. No @keyframes, no JS. (Hover →)

PHANTOM

/* base: dissolve right→left (delay descends) */
span              { opacity:0; transition:opacity .18s, transform .25s }
span:nth-child(1) { transition-delay:0.42s }  /* last to vanish  */
span:nth-child(7) { transition-delay:0.00s }  /* first to vanish */
/* hover: reveal left→right (delay ascends) */
:hover span              { opacity:1 }
:hover span:nth-child(1) { transition-delay:0.00s }  /* first to appear */
:hover span:nth-child(7) { transition-delay:0.42s }  /* last to appear  */

Demo 11 — elastic deformation

Bulge sweep scaleX wave + squash

A single fat bulge point travels left→right across the word. Every glyph runs the same scaleX keyframe, offset by index so the peak moves. At peak, the letter squashes vertically (scaleY 0.65) to conserve visual mass — exactly like a physical elastic being squeezed. The wave re-enters before the last letter finishes, so the loop is seamless.

ELASTIC

✓ Works everywhere (hardcoded)
@keyframes bulge {
  0%,100% { transform:scaleX(1) scaleY(1) }
  50%     { transform:scaleX(2.4) scaleY(.65) }
}
span:nth-child(1){animation-delay:0.00s}
span:nth-child(2){animation-delay:0.11s}
span:nth-child(3){animation-delay:0.22s}
✦ Length-independent (Chrome 138+)
/* one-liner stagger */
.word span {
  animation: bulge 2.2s infinite;
  animation-delay: calc(
    0.11s * (sibling-index() - 1)
  );
}

Demo 12 — emergence from below

Dust accumulation blur + translateY + text-shadow halos

Black letters form out of drifting black dust rising from the floor of the stage. Three CSS properties do all the work together: translateY lifts each glyph from below the clipped edge; filter: blur() keeps it dispersed while it rises; layered text-shadow rings with large radii act as the particle halos that shrink as the letter condenses. overflow: hidden on the stage is the trick that makes the dust invisible until it crosses the bottom edge. After holding solid the letters dissolve and sink back out of frame.

CONDENSE

✓ Works everywhere (hardcoded)
/* overflow:hidden on stage clips below-fold dust */
.stage    { overflow: hidden }
@keyframes dust-cohere {
  0%      { transform:translateY(3.2em);
            filter:blur(18px); opacity:0;
            text-shadow:0 .2em 14px rgba(0,0,0,.55),
              0 .6em 26px rgba(0,0,0,.3) }
  40%,62% { transform:translateY(0);
            filter:blur(0); opacity:1;
            text-shadow:none }
  100%    { transform:translateY(3.2em) }
}
✦ Length-independent (Chrome 138+)
/* stagger scales with word length */
.word span {
  animation: dust-cohere 9s
    ease-in-out infinite;
  animation-delay: calc(
    0.14s * (sibling-index() - 1)
  );
}
The honest cost. All twelve lean on one trade-off: the markup is no longer a word, it's a pile of <span>s. That's the exact "gross markup" CSS-Tricks flagged. Three rules keep it sane → (1) role="text" + aria-label so assistive tech still reads the word; (2) reserve splitting for layout/transform effects — pure-paint cases (color, decoration) are better served by the JS-driven Custom Highlight API with no DOM splitting at all; (3) the day browsers ship ::nth-letter natively, delete the spans and keep the CSS almost as-is.
