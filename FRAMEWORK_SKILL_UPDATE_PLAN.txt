FRAMEWORK SKILL UPDATE PLAN
============================
Audit date: 2026-09-23
Repository: https://github.com/greysquirr3l/claudedesignskills

Scope
-----
The 21 remaining framework skills were audited against official documentation,
GitHub releases, and npm package metadata. The PixiJS v8 skill was not included
because it was already audited and updated separately.

General update policy
---------------------
1. Add an explicit current-version/date note to each skill.
2. Prefer official APIs and package names in primary examples.
3. Move deprecated APIs into clearly labeled migration/legacy sections.
4. Label experimental, browser-dependent, backend-specific, and community APIs.
5. Pin or scope package versions where reproducibility matters.
6. Test changed code examples against the stated version.
7. Synchronize each individual skill with its bundle copy.

Priority 1: major API migrations
--------------------------------

animejs
- Current: Anime.js 4.5.0.
- Replace v3 default import/anime({...}) with named animate(targets, params).
- Replace anime.timeline() with createTimeline().
- Update easing, callbacks, loop, direction, spring, SVG, and keyframe examples
  to v4 APIs: ease, on-prefixed callbacks, reversed/alternate, repeat counts,
  createSpring(), svg.createMotionPath(), svg.createDrawable(), and to.
- Update React/Vue examples and bundle-size notes; label v3 APIs as migration-only.

locomotive-scroll
- Current: Locomotive Scroll 5.0.1, built on Lenis.
- Rewrite the v4 examples: remove required data-scroll-container and
  data-scroll-section markup, obsolete options, init(), update(), and internal
  scroll.instance access.
- Use v5 constructor/lenisOptions, resize(), native CustomEvents,
  scrollCallback, progress CSS/events, and orientation.
- Rework GSAP integration for v5/Lenis; document touch/parallax behavior.

threejs-webgl
- Current: Three.js 0.186.0/r186.
- Add an explicit version baseline and maintenance note.
- Prefer renderer.setAnimationLoop(); explain async WebGPURenderer init and
  WebGL2 fallback.
- Separate WebGL addon post-processing/GPGPU/GLSL from WebGPU/TSL APIs.
- Use PCFShadowMap for WebGPU, document texture.colorSpace and
  renderer.outputColorSpace, and remove obsolete encoding terminology.
- Dispose textures and render targets as well as geometry/material/renderer.

playcanvas-engine

- Replace deprecated model component with render and entity.render.
- Replace deprecated animation component with Anim/state graphs.
- Make ESM Script subclasses the primary scripting pattern; retain pc.createScript
  only as legacy guidance.
- Update Ammo setup to WasmModule.setConfig/getInstance and current distributions.
- Mark Model, Animation, and Classic scripts deprecated/legacy where retained.

react-three-fiber
- Current: @react-three/fiber 9.8.0; v9 pairs with React 19, v8 with React 18.
- Add version/React compatibility notes.
- Correct Canvas props: flat = tone mapping, legacy = color management,
  linear = sRGB/gamma behavior.
